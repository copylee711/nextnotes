# 界面调研：享做笔记、Saber、小米创作（2026-11-21）

在小米平板 5 Pro（横屏 2560×1600）上实际打开三款应用，记录布局和功能，作为 NextNotes 改版的参考。截图只留在本机，没有放进仓库（里面有用户的笔记）。

## 享做笔记（com.newskyer.draw）

- **首页**：常驻左侧栏（所有笔记 / 闪卡列表 / 收藏夹 / 回收站 / 备份导出 / 智能客服），右侧是封面网格，每本有收藏星标；右下角橙色 + 按钮。
- **编辑器**
  - 左侧竖排"笔盒"：真实笔的插画（钢笔、铅笔、马克笔、荧光笔、橡皮），下面是文本、形状、套索，再下面是三档粗细和颜色列表。
  - 顶栏左边：返回、页面侧栏、撤销、隐藏工具栏；右边：图片、分屏、截屏、AI（手写转文本）、加页、笔记内搜索、历史、设置。
  - 多篇笔记以标签页同时打开，可以左右分屏。
  - 右侧有页码条（1/1 加上下翻页），左下角有翻页箭头。
- **右侧抽屉**分"工具 / 导出 / 设置"三栏：
  - 工具：管理工具栏、导入网络视频、网页摘录、思维导图、手写转换文本、录音/语音识别、试卷去手写、添加图片、贴纸、记忆胶带、截屏插入、脑图、摘录闪卡、插入横向空间、尺子、放大书写、画完立刻自动识别（形状）、点状/线条激光笔、遮挡荧光笔、隐藏笔迹、图层、全屏、锁定移动、笔记密码、触控笔移动模式。
  - 设置：触控笔模式、显示笔盒、双页模式、阅读模式（只读）、显示标签、固定预览页面、翻页方向。
- **AI 按钮**其实是手写输入法：手写后转成打字文字，支持连续模式、字号和加粗、斜体等格式。

## Saber（com.adilhanney.saber）

- 首页：窄的图标侧栏（首页 / 文件夹 / 白板 / 设置），"最近笔记"卡片，右下角 + 按钮。
- 编辑器：一条底部工具栏装下全部工具（钢笔、铅笔、荧光笔、颜色、套索、形状笔、橡皮、图片、文本、手形、全屏、撤销、重做、分享）；左边三个小开关（锁定、手指书写、适应屏幕）；右上角显示缩放比例。
- 界面最干净，但图标抽象，功能少。

## 小米创作（com.miui.creation）

- 首页：大标题加大圆角卡片网格。
- 编辑器：
  - 顶部居中是"笔托"，几支笔的插画立着排开，选中的升起来；旁边只有三个颜色圆点。
  - 右上角是撤销、重做、分享、更多。
  - 纸张四周露出灰色桌面，页面带圆角；左下角显示"1/1 100%"。

## NextNotes 现状（v0.1.0 在平板上）

- 配色是 Material 3 从种子色推出来的低饱和灰粉，对比弱，看起来"土"。
- 编辑器顶栏塞了约 25 个抽象图标，平板横屏也放不下，颜色被截掉；默认看不到撤销/重做和页码；AI 按钮压在纸面左下角。
- 新建笔记页有大量未翻译的英文（New note in、Add cover、No cover、Every page、Plain paper、Built-in、Examples）。
- xnotes 其实已有遮挡胶带（TAPE）、形状魔棒（WAND）、尺子、插入空白、页面跳转、小地图、分屏、工具栏自定义（`ToolbarLayout`）、工具栏位置和悬浮（`ToolbarLook`），只是默认布局让人找不到。
